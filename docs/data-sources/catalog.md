# prepaidhost_catalog (Data Source)

Orderable packages, options and indicative prices of a product type (`GET /catalog/{type}`). The API caches the catalog for up to five minutes; the binding price is always the quote of the order. Which attributes are filled depends on `type`: `rootserver` fills `options`, `durations` and `templates`, `rootpacket` fills `packets`, `durations_months` and `templates`, `domain` fills `tlds` and `durations_months`. The others are null.

## Example Usage

```terraform
# Orderable root packets with their prices, durations and OS templates.
data "prepaidhost_catalog" "packets" {
  type = "rootpacket"
}

output "packets" {
  value = data.prepaidhost_catalog.packets.packets
}

output "templates" {
  value = data.prepaidhost_catalog.packets.templates
}
```
