# prepaidhost_domain (Resource)

A domain, registered and paid from the prepaid balance. The TLD must be in the `prepaidhost_catalog` data source (type `domain`); the owner is a `prepaidhost_domain_contact`.

**Creating the resource spends money.** Create quotes the order, checks `max_price`, orders with a deterministic Idempotency-Key and waits until the registrar accepted the registration. An apply repeated after an abort (even in a new process) gets the paid order back instead of buying again, and a live domain with the same `name` that was ordered through the API is taken over instead of buying it again (with a warning, and auto-renew switched on again). A domain registered in the customer panel cannot be taken over this way: the order answers `DOMAIN_UNAVAILABLE` (it is registered) — bring it in with `terraform import` instead. Domain transfers are not available through the API yet; order them in the customer panel and import the domain.

**Destroying the resource cancels, it does not delete:** auto-renew is switched off and the domain stays registered until `expires_at`; after that it is not renewed and the registration lapses. There is no refund for the remaining term. Applying the same configuration before that date takes a domain ordered through the API over again without a new purchase; an imported (panel) domain has to be imported again.

The purchase arguments (`name`, `duration_months`, `action`) are never changed in place and never replace the domain: a change is a plan error. `nameservers` and `auto_renew` are updated in place.

A domain deleted outside Terraform is removed from the state. A domain whose term expired stays in the state with `status = "expired"` as long as the API lists it: the platform does not renew it any more; renew it in the panel while the registry allows it, or destroy it.

Needs a token with the scopes `domain:order` (ordering), `domain:read`, `domain:renew` (term and auto-renew) and `domain:nameserver` (only when `nameservers` is set).

## Example Usage

```terraform
resource "prepaidhost_domain_contact" "owner" {
  type      = "PERS"
  sex       = "MALE"
  firstname = "Max"
  lastname  = "Mustermann"
  street    = "Musterstrasse"
  number    = "1"
  postcode  = "12345"
  city      = "Berlin"
  country   = "DE"
  phone     = "+49.3012345678"
  email     = "max@example.com"
}

resource "prepaidhost_domain" "main" {
  name            = "example.de"
  duration_months = 12
  contact_id      = tonumber(prepaidhost_domain_contact.owner.id)

  # Creating this resource charges the balance (the price of the whole term).
  max_price = 15

  nameservers = ["ns1.example.net", "ns2.example.net"]
}
```

## Schema

### Required

- `contact_id` (Number) Id of the domain contact (`prepaidhost_domain_contact`) that becomes the owner. Only used when buying: changing it later does not change the registrant (a plan warning says so; change the owner in the panel). The API cannot read it back.
- `name` (String) Fully qualified domain name in lower case without trailing dot, e.g. `example.de` or `shop.co.uk` (punycode for internationalised names). The first label is the second-level domain, the rest the TLD, which must be in the catalog. At most 64 characters: the name is the order's client reference and part of its Idempotency-Key, so it identifies the purchased domain. Part of the purchase: changing it later is a plan error, never a new purchase.

### Optional

- `action` (String) Only `register` (the default; the API checks that the name is available). Transfers are not available through the API yet: order them in the customer panel and import the domain. The API cannot read it back. Part of the purchase: changing it later is a plan error, never a new purchase.
- `auto_renew` (Boolean) Renew the domain automatically from the balance before its term ends. Defaults to `true`.
- `create_timeout` (String) How long Create may take, including the registrar's confirmation (Go duration). Defaults to `30m`. If it runs out after the order was paid, apply again: the same order is taken over, nothing is bought twice.
- `duration_months` (Number) Term in months: 12, 24 or 36. Defaults to `12`. The API cannot read it back. Part of the purchase: changing it later is a plan error, never a new purchase.
- `max_price` (Number) Highest order total in EUR this apply may spend. A higher quote is an error before anything is ordered. Only used when buying.
- `nameservers` (List of String) 2 to 4 nameservers (lower case, no trailing dot, no IP addresses), set at the registrar. Without it the provider does not manage them and only reads them (a new domain uses the platform's `ns1`–`ns4.prepaid-host.com`). Removing it from the configuration keeps the current nameservers; to go back to the platform's, set those four explicitly.
- `promo_code` (String) Promo code for the order. Only used when buying.

### Read-Only

- `expires_at` (String) End of the paid term (RFC 3339, UTC). After `terraform destroy` the domain stays registered until then.
- `id` (String) Domain id.
- `status` (String) `active`; `expired` when the term ran out; `provisioning` while a taken-over domain's earlier order is not active yet (the registration is not finished).

## Import

Import is supported using the following syntax. Use `tofu import` instead of `terraform import` with OpenTofu.

```shell
# A domain registered or transferred in the customer panel is imported by its
# numeric id. Domain transfers are not available through the API.
terraform import prepaidhost_domain.main 1234
```
