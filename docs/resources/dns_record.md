# prepaidhost_dns_record (Resource)

A DNS record in the zone of a domain of the account (`prepaidhost_domain`). The zone lives at the platform's DNS provider; its apex NS records are read-only and cannot be managed.

A record deleted outside Terraform is removed from the state and created again by the next apply; a changed one is set back. Changing `type` (or `domain_id`) replaces the record, everything else is changed in place.

Import with `domain_id/record_id`, e.g. `terraform import prepaidhost_dns_record.www 1234/567890` (the record ids are listed by `GET /domain/{id}/dns`).

Needs a token with the scopes `domain:dns:read` and `domain:dns:write`.

## Example Usage

```terraform
variable "contact_id" {
  description = "Id of a prepaidhost_domain_contact."
  type        = number
}

# The zone of a domain of the account. An existing domain can be imported, see
# the prepaidhost_domain resource.
resource "prepaidhost_domain" "main" {
  name       = "example.de"
  contact_id = var.contact_id
  max_price  = 15
}

resource "prepaidhost_dns_record" "www" {
  domain_id = tonumber(prepaidhost_domain.main.id)
  type      = "A"
  host      = "www"
  record    = "203.0.113.10"
  ttl       = 300
}

resource "prepaidhost_dns_record" "mail" {
  domain_id = tonumber(prepaidhost_domain.main.id)
  type      = "MX"
  host      = "@"
  record    = "mail.example.net"
  priority  = 10
}
```

## Schema

### Required

- `domain_id` (Number) Id of the domain whose zone holds the record. Changing it replaces the record.
- `record` (String) Value of the record (address, target host or text), at most 2048 characters. Target hosts of `CNAME`, `MX` and `SRV` are written without trailing dot (`mail.example.com`). `TXT` values are sent verbatim.
- `type` (String) Record type in upper case: `A`, `AAAA`, `CNAME`, `MX`, `TXT` or `SRV`. Changing it replaces the record (the API cannot change a record's type).

### Optional

- `host` (String) Host relative to the zone in lower case, e.g. `www` or `_dmarc`; `@` (the default) is the zone root.
- `port` (Number) Port (1–65535), required for `SRV` and only allowed there.
- `priority` (Number) Priority (0–65535), only for `MX` and `SRV`. Without it the API uses 10 for MX and 0 for SRV. Removing it from the configuration keeps the current value.
- `ttl` (Number) TTL in seconds, one of 60, 300, 600, 900, 1800, 3600, 21600, 43200, 86400, 172800, 259200, 604800, 1209600, 2592000. Defaults to `300`.
- `weight` (Number) Weight (0–65535), required for `SRV` and only allowed there.

### Read-Only

- `id` (String) Record id at the DNS provider.

## Import

Import is supported using the following syntax. Use `tofu import` instead of `terraform import` with OpenTofu.

```shell
# The import id is domain_id/record_id.
terraform import prepaidhost_dns_record.www 1234/567890
```
