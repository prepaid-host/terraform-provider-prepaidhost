# prepaidhost_domain_contact (Resource)

A registrant contact for domain orders (`POST /account/domain-contacts`). Needs a token with the `domain:contact` scope; the contact `id` is used as the holder when ordering a domain.

**The API can neither change nor delete contacts.** Every argument change therefore replaces the resource, which only works when first name, last name and email differ (the API refuses a second contact with the same ones). Destroying the resource only removes it from the Terraform state; the contact stays in the account and can be removed in the customer panel. If an identical contact already exists, it is adopted instead of created. `fax` and the identification fields are never returned by the API: after `terraform import` they are null in the state, and the first apply with a configured value adopts it in place without replacing the contact.

An account holds at most 10 contacts.

~> **Note:** Sensitive values (the identification fields) are hidden in plan output but are still stored in the state file in plain text. Protect your state.

## Example Usage

```terraform
resource "prepaidhost_domain_contact" "owner" {
  type      = "PERS"
  sex       = "MALE"
  firstname = "Max"
  lastname  = "Mustermann"
  street    = "Musterstrasse"
  number    = "1"
  postcode  = "12345"
  city      = "Berlin"
  country   = "DE"
  phone     = "+49.3012345678"
  email     = "max@example.com"
}
```

## Schema

### Required

- `city` (String) City.
- `country` (String) Two-letter ISO 3166-1 country code, for example `DE`.
- `email` (String) Email address. The API stores it in lowercase.
- `firstname` (String) First name.
- `lastname` (String) Last name.
- `number` (String) House number.
- `phone` (String) Phone number in international format, for example `+49.3012345678`.
- `postcode` (String) Postal code.
- `sex` (String) `MALE`, `FEMALE` or `UNKNOWN`.
- `street` (String) Street without house number.
- `type` (String) `PERS` (person) or `ORG` (organisation; needs `organisation`).

### Optional

- `countryofbirth` (String, Sensitive) Country of birth, two-letter ISO code. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `dateofbirth` (String, Sensitive) Date of birth (`YYYY-MM-DD`). Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `fax` (String) Fax number. The API does not return it.
- `idcard` (String, Sensitive) Identity card number. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `idcardauthority` (String, Sensitive) Authority that issued the identity card. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `idcardissuedate` (String, Sensitive) Issue date of the identity card (`YYYY-MM-DD`). Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `is_default` (Boolean) Make this the default contact. Evaluated when the contact is created; the first contact of an account is always the default. Read from the API on import only.
- `name` (String) Optional label of the contact.
- `organisation` (String) Organisation name. Required for `type = "ORG"`.
- `placeofbirth` (String, Sensitive) Place of birth. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `region` (String) Region or state. Defaults to the city.
- `regionofbirth` (String, Sensitive) Region of birth. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `registrationnumber` (String, Sensitive) Commercial register number of an organisation. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `taxnr` (String, Sensitive) Tax number. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.
- `vatnr` (String, Sensitive) VAT id. Only needed for TLDs that require identification of the holder (for example `.it`). The API never returns it.

### Read-Only

- `api_handle_id` (String) Handle id at the registrar; null if the registrar was not reachable on creation.
- `handle_code` (String) Handle code of the contact; null until the contact is used.
- `id` (String) Contact id (the holder id for domain orders).

## Import

Import is supported using the following syntax. Use `tofu import` instead of `terraform import` with OpenTofu.

```shell
# The import id is the numeric id of the contact.
terraform import prepaidhost_domain_contact.owner 1234
```
