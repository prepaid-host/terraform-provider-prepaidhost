# prepaidhost_ssh_key (Resource)

A public SSH key stored in the account, which can be installed on vServers. Storing keys is free. Needs a token with the `account:sshkeys` scope. The API has no update, so changing any argument replaces the key.

Destroying the resource removes the key from the account only; keys already installed on servers stay there.

## Example Usage

```terraform
resource "prepaidhost_ssh_key" "deploy" {
  name       = "deploy"
  public_key = file("~/.ssh/id_ed25519.pub")
}
```

## Schema

### Required

- `name` (String) Display name of the key (max. 100 characters).
- `public_key` (String) The public key in OpenSSH format, for example `ssh-ed25519 AAAA... user@host`. The API never returns it, so it is not set after `terraform import`: the first apply with the configured key fills it in (without replacing the key) if its fingerprint matches the imported key.

### Optional

- `provision_on_reinstall` (Boolean) Install this key automatically on every reinstall of a vServer. Defaults to `false`.

### Read-Only

- `created_at` (String) When the key was stored (RFC 3339).
- `fingerprint` (String) Fingerprint of the key as the API reports it (MD5, colon-separated hex pairs).
- `id` (String) Key id in the account.

## Import

Import is supported using the following syntax. Use `tofu import` instead of `terraform import` with OpenTofu.

```shell
# The import id is the numeric id of the key (customer panel or API).
terraform import prepaidhost_ssh_key.deploy 1234
```
