# prepaidhost_vserver (Resource)

A vServer (rootserver), bought from the prepaid balance. Either a root packet (`packet_id` + `duration_months`) or a custom server (`cores`, `memory`, `disk`, `addresses`, `backups`, `traffic`, `duration_days`) — see the `prepaidhost_catalog` data source for the values.

**Creating the resource spends money.** Create quotes the order, checks `max_price`, orders with a deterministic Idempotency-Key and waits until the server is installed. An apply repeated after an abort (even in a new process) gets the paid order back instead of buying again; a live server with the same `hostname` is taken over instead of buying a second one (with a warning, and auto-renew switched on again).

**Destroying the resource cancels, it does not delete:** auto-renew is switched off and the server keeps running until `expires_at`. There is no refund for the remaining term. Applying the same configuration (same `hostname`) before that date takes the server over again without a new purchase.

The purchase arguments (`hostname`, `packet_id`, `duration_months`, `cores`, `memory`, `disk`, `addresses`, `backups`, `traffic`, `duration_days`, `template_id`) are never changed in place and never replace the server: a change is a plan error. Only `display_name` and `auto_renew` are updated in place.

A server deleted outside Terraform is removed from the state; the next apply buys a new one. A server whose term expired stays in the state with `status = "expired"` as long as the API still lists it: with auto-renew on, the platform may still renew it for about a day after expiry, and it is deleted a few days later. Renew it in the panel, or destroy it to stop renewal.

`create_before_destroy` or `taint` with an unchanged configuration takes the same server over again (no purchase); the delete of the deposed object then switches auto-renew off, which the next plan shows as a one-time change of `auto_renew` from false to true.

Rarely, a server whose rental record was removed on the platform makes reads fail with HTTP 500; remove it with `terraform state rm` then.

Needs a token with the scopes `rootserver:order` (ordering), `rootserver:read`, `rootserver:network:read` (addresses) and `rootserver:renew` (auto-renew).

## Example Usage

```terraform
resource "prepaidhost_ssh_key" "deploy" {
  name       = "deploy"
  public_key = file("~/.ssh/id_ed25519.pub")
}

# A root packet. Look up packet_id and template_id with the
# prepaidhost_catalog data source (type "rootpacket").
resource "prepaidhost_vserver" "web" {
  hostname        = "web1"
  packet_id       = 2
  duration_months = 1
  template_id     = 12
  ssh_key_ids     = [tonumber(prepaidhost_ssh_key.deploy.id)]

  # Creating this resource charges the balance. Refuse any order above 20 EUR.
  max_price = 20
}

# A custom server instead of a packet: cores, memory (MB), disk (GB),
# addresses, backups, traffic and duration_days come from the catalog
# (type "rootserver").
resource "prepaidhost_vserver" "custom" {
  hostname      = "worker1"
  cores         = 2
  memory        = 2048
  disk          = 40
  addresses     = 1
  backups       = 1
  traffic       = "unlimited"
  duration_days = 30
  template_id   = 12
  max_price     = 30
}
```

## Schema

### Required

- `hostname` (String) Hostname of the server (1–63 letters, digits and hyphens, no dots). It is the order's client reference and part of its Idempotency-Key, so it identifies the purchased server: while a live server carries it, ordering the same hostname takes that server over instead of buying another. To rename the server in the panel use `display_name`. The API cannot read it back; after `terraform import` the configured value is taken as is. Part of the purchase: changing it later is a plan error, never a new purchase.
- `template_id` (Number) Operating system template (`prepaidhost_catalog` → `templates`). Part of the purchase: changing it later is a plan error, never a new purchase.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `addresses` (Number) Number of IPv4 addresses of a custom server. Part of the purchase: changing it later is a plan error, never a new purchase.
- `auto_renew` (Boolean) Renew the server automatically from the balance when its term ends. Defaults to `true`.
- `backups` (Number) Backup slots of a custom server. Part of the purchase: changing it later is a plan error, never a new purchase.
- `cores` (Number) vCores of a custom server. Part of the purchase: changing it later is a plan error, never a new purchase.
- `create_timeout` (String) How long Create may take, including the installation (Go duration, e.g. `30m`, `1h`). Defaults to `30m`. If it runs out after the order was paid, apply again: the same order is taken over, nothing is bought twice.
- `disk` (Number) Disk of a custom server in GB. Part of the purchase: changing it later is a plan error, never a new purchase.
- `display_name` (String) Name of the server in the panel (4–32 characters); changed in place. The API cannot read it back. Without it, a newly bought server is named after `hostname` (which may be shorter than 4 or longer than 32 characters — copied into the configuration it then fails this validation, so choose a valid name instead), and for a server that was taken over or imported it stays unknown (null).
- `duration_days` (Number) Term of a custom server in days: 30, 90, 180 or 365 (rented as 1, 3, 6 or 12 months). The API cannot read it back. Part of the purchase: changing it later is a plan error, never a new purchase.
- `duration_months` (Number) Term of a root packet in months: 1, 3, 6 or 12. Requires `packet_id`. Part of the purchase: changing it later is a plan error, never a new purchase.
- `max_price` (Number) Highest order total in EUR this apply may spend. A higher quote is an error before anything is ordered. Only used when buying.
- `memory` (Number) Memory of a custom server in MB (catalog value, e.g. `2048`). Part of the purchase: changing it later is a plan error, never a new purchase.
- `packet_id` (Number) Root packet to buy (`prepaidhost_catalog` type `rootpacket`). Conflicts with the custom arguments. Part of the purchase: changing it later is a plan error, never a new purchase.
- `packet_promo_code` (String) Promotion keyword of a root packet (sent as the packet item's `promo_code`); without it the packet's active promotion applies. Requires `packet_id`. Only used when buying.
- `password` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) Root/Administrator password (at least 6 characters; Windows templates have stricter rules). Write-only: it is sent with the order and never stored in the state. Without it the API generates one. Only used when buying. Needs Terraform 1.11+ or OpenTofu 1.11+.
- `promo_code` (String) Promo code for the order (order-level `promo_code`). Only used when buying.
- `ssh_key_ids` (Set of Number) Ids of SSH keys of the account (`prepaidhost_ssh_key`) to install. Only used when buying; changing it later does not touch the server.
- `traffic` (String) Traffic option of a custom server (catalog value, e.g. `unlimited`). The API cannot read it back. Part of the purchase: changing it later is a plan error, never a new purchase.

### Read-Only

- `expires_at` (String) End of the paid term (RFC 3339, UTC). After `terraform destroy` the server runs until then.
- `id` (String) vServer id.
- `ipv4_addresses` (List of String) IPv4 addresses of the server.
- `status` (String) `active` when installed, `installing` otherwise (e.g. during a reinstall), `expired` when the term ran out.

## Import

Import is supported using the following syntax. Use `tofu import` instead of `terraform import` with OpenTofu.

```shell
# A vServer ordered in the customer panel needs an import before Terraform manages it.
# The import id is the numeric id of the server; afterwards set the purchase
# arguments in the configuration to what was bought (they cannot all be read back).
terraform import prepaidhost_vserver.web 1234
```
